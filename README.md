\# Python Free-Fall Calculator



A Python project demonstrating Git version control.



The program calculates the displacement of an object

released from rest under constant gravitational acceleration,

neglecting air resistance.



The displacement is:



d(t) = 1/2 \* g \* t^2



where g = 9.81 m/s^2.



\## Execution



Run the program using:



python main.py
